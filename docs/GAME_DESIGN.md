# Under the Orchard — дизайн-документ (v0.2, прототип)

> Живой документ. Меняем по ходу разработки: если решение изменилось — правим здесь, а не держим в голове.

## 1. Идея в одном абзаце

Уютная 2D-игра с **видом сверху** и спокойным ритмом фермы (жанр фермерских игр в духе Stardew Valley; свой мир, свой арт). Герой получает заброшенный фруктовый сад на склоне холма. **На поверхности** — сад, грядки и дом, который можно отстраивать. **Под садом**, вход у корней старого дерева, — шахта из этажей с рудой и тайнами. Сад кормит героя, шахта даёт материалы, материалы превращаются в инструменты и постройки, которые делают сад лучше и позволяют копать глубже.

**Настроение:** тёплое, неспешное, без стресса. Нет проигрыша, нет жёстких таймеров. Игра для того, чтобы расслабиться вечером.

## 2. Столпы (по ним проверяем каждую фичу)

1. **Расслабление важнее вызова.** Если механика вызывает стресс — упрощаем или убираем.
2. **Верх и низ связаны.** Каждая система должна давать что-то другой половине мира.
3. **Видимый прогресс.** Игрок всегда видит, что его сад/дом/шахта стали лучше, чем вчера.
4. **Маленький объём, высокое качество.** Лучше 5 механик, которые приятно ощущаются, чем 20 сырых.

## 3. Основной цикл

```
Утро → полить/собрать урожай в саду
     → спуститься в шахту, накопать руды и камня
     → вернуться, скрафтить инструмент или часть постройки
     → построить/улучшить что-то в саду
Вечер → лечь спать → новый день, растения выросли
```

Короткий цикл (минуты): разбить камень → получить ресурс → положить в инвентарь.
Средний цикл (день): ферма + шахта + крафт.
Длинный цикл (недели игрового времени): улучшение дома, кирки, открытие новых этажей шахты.

## 4. Мир

- **Вид:** 2D сверху (top-down), тайловый мир (тайл 16×16 px). Игрок ходит свободно (включая диагональ, скорость выровнена), смотрит в одну из 4 сторон; без прыжков и гравитации.
- **Две зоны:**
  1. **Сад (поверхность)** — одна карта, сделанная вручную: трава, деревья, грядки, дом героя, вход в шахту у корней дерева.
  2. **Шахта** — отдельные карты-этажи. На этаже лежат камни и руда, их разбивают киркой. Где-то под камнем спрятана **лестница вниз**; на каждом этаже есть лестница наверх — она ведёт сразу в сад.
- **Глубина = ценность:** чем глубже этаж, тем ценнее руда.
  - Этажи 1–4 — камень, уголь.
  - Этажи 5+ — медь (в полной версии нужна медная кирка; в прототипе без крафта медь бьётся деревянной киркой, но за 5 ударов).
  - *(после прототипа)* глубокие этажи — железо, кристаллы, светящиеся грибы.
- **Генерация этажей:** фиксированная форма пещеры + случайная расстановка камней и руды по правилам глубины. Сад делаем вручную.

## 5. Механики

### 5.1 Прототип (MVP)
> **Веб-прототип (учебная сдача):** из списка ниже делаем только три механики — **движение**, **шахту с камнями** и **грядку с ростом по дням**. Крафт, сон, сохранение добавим в полной версии, если ядро понравится. Цель прототипа — проверить, приятно ли копать и сажать.

| Механика | Что минимально нужно |
|---|---|
| Движение | Свободная ходьба (с диагональю), взгляд в 4 стороны, столкновения со стенами/объектами, камера следует за игроком |
| Шахта | Вход в саду → этаж с камнями; удар киркой по камню рядом → он разбивается (2–3 удара) → ресурс в инвентарь; найти лестницу → следующий этаж |
| Инвентарь | Хотбар на 8–10 слотов, стаки предметов, выбор слота цифрами/колёсиком |
| Ферма | Мотыга вскапывает землю → посадить семя → полить лейкой → растёт по дням (3–4 стадии) → собрать |
| Смена дней | Часы игрового времени, день/вечер (затемнение экрана), сон в кровати = новый день |
| Крафт | Простой список рецептов у верстака: «3 камня + 2 дерева → кирка» |
| Сохранение | Сохранить/загрузить мир и инвентарь в JSON-файл |

### 5.2 После прототипа (идеи на потом)
- Постройки: курятник, теплица, сарай, улучшение дома (комнаты).
- Установка объектов в саду: дорожки, заборы, сундуки (бывшая «установка блоков» из вида сбоку).
- Фруктовые деревья — растут сезонами, это «визитная карточка» игры.
- Сезоны (4 по 14 дней).
- Освещение в шахтах: факелы, светящиеся грибы.
- Простые безопасные существа в пещерах (без боёвки или с очень мягкой).
- Продажа урожая через ящик у дома → монеты → магазин семян.
- Рыбалка в подземном озере.
- NPC-сосед или странствующий торговец.

### 5.3 Сознательно НЕ делаем в прототипе
Боевая система, мультиплеер, бесконечный мир, диалоги и квесты, сложная экономика, анимации персонажа сверх базовых.

## 7. Визуал и звук

- Пиксель-арт 16×16, мягкая тёплая палитра (зелёные/охристые сверху, синевато-фиолетовые в шахтах).
- На старте — **бесплатные ассеты-заглушки** (например, наборы Kenney, ассеты с itch.io с лицензией CC0). Свой арт — позже.
- Звук: тихая фоновая музыка, мягкие звуки копания и сбора. Тоже из бесплатных библиотек на старте.

## 8. Технический стек

> **Веб-прототип (сначала):** TypeScript + Phaser 3 + Vite, запуск в браузере. Окружение — **Docker** (контейнер с Node: dev-сервер с автообновлением и сборка), Node на компьютер не ставим. Черновой, для проверки ядра. Разработка в ветке `prototype`. Версионность — git + GitHub.
> **Полная версия (ниже):** на Godot, если прототип себя оправдает.

- **Движок:** Godot 4 (актуальная стабильная версия), язык **GDScript**.
- **Платформа:** Windows (ПК).
- **Мир:** `TileMapLayer` (+ `TileSet`) — отдельные слои для земли, объектов (камни, деревья), грядок. Сад и каждый этаж шахты — отдельные сцены.
- **Глобальные синглтоны (Autoload):**
  - `GameState` — текущий день, время, деньги, флаги прогресса.
  - `Inventory` — содержимое инвентаря, сигналы об изменениях.
  - `ItemDB` — описание всех предметов (из ресурсов/JSON).
  - `SaveSystem` — сохранение/загрузка.
- **Данные:** предметы, рецепты и растения описываем как данные (`Resource` или JSON), а не хардкодим в скриптах.
- **Контроль версий:** git с первого дня, коммит после каждого рабочего шага.

| Этап | Цель | Готово, когда… |

| **M2. Копаем** | Этаж шахты, разбивание камней, простой хотбар | Разбил камни, ресурсы в хотбаре |
| **M3. Шахта** | Генерация этажей, лестницы, руда по глубине | Спустился на 5 этажей, глубже — медь |
| **M4. Ферма** | Мотыга, семена, полив, рост, урожай | Посадил → поспал → собрал |
| **M5. День и сон** | Часы, затемнение, кровать | Цикл дней работает, растения растут по дням |
| **M6. Крафт** | Верстак и 4–6 рецептов | Скрафтил медную кирку и копаешь твёрдый камень |

После M8 — играем сами, записываем, что понравилось и что нет, выбираем фичи из раздела 5.2.
